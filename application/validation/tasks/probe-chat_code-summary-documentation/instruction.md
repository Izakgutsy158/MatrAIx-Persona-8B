# Coding help chat

A teammate pinged you asking for a small `stats.py` helper module — three
functions they can copy straight into their script:

- `mean(nums)` — the arithmetic average of a list of numbers
- `median(nums)` — the middle value (average of the two middle values if the
  list length is even)
- `mode(nums)` — the most frequently occurring value

In your **first message**, paste exactly what you'd send them (the way you
normally would when handing code to a teammate — your own natural style, not a
stripped-down version), then ask if it works for what they need.

Then continue for at least one more exchange, reacting to their reply.
