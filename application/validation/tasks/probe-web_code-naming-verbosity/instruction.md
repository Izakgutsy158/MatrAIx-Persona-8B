# Coding task

Paste your code directly in your reply as a ```python code block```. **Do not
create any files or use the terminal.**

Write a Python function that takes a list of exam scores and a passing threshold,
and returns the average of the scores at or above the threshold (returning 0 if
none qualify). Write it with an explicit `for` loop rather than comprehensions,
`sum`, `len`, or `filter`.

Write the function exactly the way you personally write code in your own editor.
Your own naming, formatting, and habits should show through — write it as *you*
would for your own project, not a stripped-down version.
