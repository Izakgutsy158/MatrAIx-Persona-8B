# Short writing task

A terminal is available on this Linux desktop. To open it: press
**Ctrl+Alt+T**, or if a terminal window is already visible, click it to focus.

In the terminal, create the file `/app/output/answer.txt` containing a message to
a coworker asking them to resend a file they forgot to attach to an email.

Write the message the way that feels natural to you — there are no style
requirements. Then save the file.

Tip: you can write it with a heredoc, e.g.
`mkdir -p /app/output && cat > /app/output/answer.txt <<'EOF'` … your message … `EOF`.
