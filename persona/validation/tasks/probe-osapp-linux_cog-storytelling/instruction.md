# Short writing task

A terminal is already open on this Linux desktop (if you don't see one, press
**Ctrl+Alt+T**). You only need one command: write your answer to the question
below into `/app/output/answer.txt` using a heredoc, like this —

```
mkdir -p /app/output && cat > /app/output/answer.txt <<'EOF'
<your answer here>
EOF
```

The question: *how did you get into the work or hobby you care most about? Walk
me through how it started and what's kept you with it.*

Write the answer in your own natural way — take it wherever you like, and take as
much space as you want. There are no length or style requirements.
