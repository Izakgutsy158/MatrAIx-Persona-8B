# Coding task

Paste your code directly in your reply as a ```python code block```. **Do not
create any files or use the terminal.**

Write a Python function `fizzbuzz(n)` that prints 1..n but "Fizz" for multiples
of 3, "Buzz" for 5, "FizzBuzz" for both.

Write the function exactly the way you personally write code in your own editor.
Your own commenting habits, naming, and formatting should show through — write it
as *you* would for your own project, not a stripped-down version.
