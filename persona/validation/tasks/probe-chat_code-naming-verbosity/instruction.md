# Coding help chat

You're chatting with an assistant to get a second opinion on some code.

In your **first message**, greet the assistant and paste your own Python
function that takes a list of exam scores and a passing threshold, and returns
the average of the scores at or above the threshold (returning 0 if none
qualify), written with an explicit `for` loop rather than comprehensions,
`sum`, `len`, or `filter`. Write the code just as you would for your own
project. Ask the assistant to review it.

Then continue for at least one more exchange, reacting to the assistant's reply.
